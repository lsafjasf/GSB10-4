2. 退化输入的确定行为
========================================================================
  先验含 0          -> 合法；该假设 log p = -inf，任何观测都无法复活（精确排除）
  先验全 0          -> DegeneratePriorError: 先验全为零，总质量为零
  似然含 0          -> 合法；对应假设 log p = -inf，后验退化为点质量
  观测似然全 0      -> ZeroEvidenceError（状态已回滚）: 该观测下所有假设似然均为零（log Z = -inf），后验无定义；状态已回滚
  先验含负数         -> DegeneratePriorError（拒绝构造）
  先验含 NaN       -> DegeneratePriorError（拒绝构造）
  似然含 NaN        -> ValueError（状态不变）
  全部退化用例断言通过。
