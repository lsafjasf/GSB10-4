# 环形缓冲区（ringbuf）—— 库 + 自测

纯 Python 3 标准库实现，无第三方依赖。测试环境：Python 3.12.3 / Linux x86-64。

## 文件

| 文件 | 说明 |
|---|---|
| `ringbuf.py` | 库：`RingBuffer`（非线程安全）+ `BlockingRingBuffer`（生产消费阻塞版） |
| `selftest.py` | 自测：边界/回绕分段/对拍/并发压测（unittest） |
| `bench.py` | 100 万次读写吞吐与内存压测 |

## 指针与游标比较规则

容量 `C`，内部存储为长度恰好 `C` 的 `bytearray`：

- `_r` 读游标：最旧未读字节下标，∈ [0, C)；`_w` 写游标：下一个可写下标，∈ [0, C)。
- 游标只按 `mod C` 推进，**禁止直接比较大小**（`_r < _w` 在回绕后无意义）。
- `_n` 可读字节数 ∈ [0, C]，是唯一状态判据：
  - **空 ⇔ `_n == 0`，满 ⇔ `_n == C`**；两种状态下都有 `_r == _w`，
    所以 `_r == _w` 本身有歧义，必须用 `_n` 消歧（计数器方案，C 个字节全部可用，
    不采用"牺牲一个槽位"方案）。
- 连续段长度由 `_n` 与 `C - 游标` 推出：读 n 字节时第一段 `k = min(n, C - _r)`，
  回绕段 `n - k`（可为 0）；写侧同理。
- 不变量（`check_invariants()` 断言，测试中每步校验）：
  `0 ≤ _r,_w < C`，`0 ≤ _n ≤ C`，`(_r + _n) % C == _w`。

并发语义：`BlockingRingBuffer.put` 把一条消息**原子**写入（空间不足整体等待，
绝不留下半包、绝不覆盖未读数据）；`get(n)` 阻塞直到读满 n 字节。
（曾验证过"部分写+等待"实现会让多生产者的消息交错——字节流不错但帧边界错位，
因此改为整条原子写。）

## 运行命令

```bash
cd ringbuf
python3 selftest.py          # 全部自测
python3 selftest.py basic    # 仅边界 + 回绕分段
python3 selftest.py diff     # 仅对拍
python3 selftest.py concur   # 仅并发压测
python3 bench.py             # 吞吐/内存压测
```

## 自测结果（python3 selftest.py，7 项全部 OK，约 4s）

- **空缓冲区**：`read` 返回空、分段视图为空、状态位正确。
- **满缓冲区**：`write` 返回 0、`write_all` 抛 `BufferFull`，未读数据零覆盖。
- **单字节读写**：200 次写 1 读 1 交替，内容顺序逐字节一致。
- **跨回绕分段**：cap=8、r=4/w=5 时一次写 6 字节 → 落盘为 3+3 两段；
  `read_segments()` 返回 2 段 `[ABCD][EFG]`，`peek/read` 跨段拼接得 `ABCDEFG`。
- **边界写**：写长恰好等于到末尾距离，游标正确回绕到 0。

## 对拍数据（与朴素大数组逐字节对拍）

参照实现 `NaiveRingModel`：无限 `bytearray` + head 下标的朴素 FIFO（不回绕、
不覆盖）。随机种子 20261005，200 轮 × 300 次随机读/写，容量 ∈ {1,2,3,7,8,13,64}，
每步比较"环形可读内容 == 朴素队列内容"并校验不变量：

```
[对拍] seed=20261005 trials=200 操作/trial=300
[对拍] 逐字节校验字节数=584885 回绕事件=3730 不一致=0
[对拍] 样本（容量, 环形可读内容hex == 朴素队列hex）:
        cap= 3  4f300b
        cap= 3  0b
        cap= 3  58f245
```

## 并发压测校验结果

4 生产者 × 4 消费者，容量 53（故意不是包长 8 的整数倍，强制回绕与等空间），
每生产者 25000 个定长 8 字节包（pid + 序号 + 校验载荷），共 100000 包。
消费者校验：每生产者序号严格连续（错序/丢包检测）+ 载荷重算比对（覆盖检测）：

```
[并发] 每生产者收包=[25000, 25000, 25000, 25000] 总收包=100000
[并发] 错误（覆盖/丢包/错序/损坏）=0  耗时=3.84s  吞吐=26067 包/s
```

## 吞吐与内存（python3 bench.py，100 万次写 + 100 万次读）

| 容量 | 块大小 | 耗时 | 吞吐 | 带宽 | tracemalloc 峰值 |
|---|---|---|---|---|---|
| 64 | 1 B | 3.06 s | 0.65 Mops/s | 0.3 MB/s | 0.2 KiB |
| 4096 | 64 B | 6.42 s | 0.31 Mops/s | 10.0 MB/s | 0.4 KiB |
| 65536 | 4096 B | 7.42 s | 0.27 Mops/s | 552 MB/s | 8.3 KiB |

- 内存：`RingBuffer(65536)` 对象 48 B + 底层 bytearray 65593 B，
  占用只与容量成正比，**不随读写次数增长**；压测全程进程峰值 RSS 11.1 MiB。
- 单字节情形吞吐最低（每次操作都有 Python 层开销且游标持续回绕），
  大块情形接近 memcpy 上限。
