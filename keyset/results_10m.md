# 1000 万行深度翻页基准结果

- 数据量: 10,000,000 行（score 为 0..1e9 随机整数，有重复）
- page_size=1,000，总页数 10,000；索引: (score, id) 复合 B+树
- 计时含 SQL 执行 + fetchall 取页；OFFSET 每点取 2 次最小值

- 单页均值 0.207 ms，p50 0.198 ms，p95 0.252 ms

- 线性拟合: 耗时 ≈ -0.01 + 6479.3805 ms / 百万行扫描
- 外推末页(第 10,000 页)单页 ≈ **0.1 s**，而键集末页实测 0.226 ms
- OFFSET 全量翻 10000 页约需 324 s（0.1 小时），键集 2.1 s
