# 模板变量填充：语法与转义说明

纯 Python 3 标准库实现，无第三方依赖。

## 1. 占位符语法

- 形式：`{{ name }}`，两侧空白可有可无，`{{name}}`、`{{  name }}` 等价。
- 变量名：`[A-Za-z_][A-Za-z0-9_]*`，非法名字抛 `TemplateSyntaxError`。
- 模板中未闭合的 `{{` 抛 `TemplateSyntaxError`，不会产出半成品输出。
- 单独出现的 `{`、`}`、`}}` 都是普通字符，不影响模板结构。

## 2. 转义规则（反斜杠引导）

| 写法 | 输出 | 说明 |
|------|------|------|
| `\{{` | `{{` | 花括号还原为字面量，不解析成占位符 |
| `\}}` | `}}` | 同上 |
| `\\` | `\` | 转义反斜杠本身 |
| `\x`（x 非 `{ } \`） | `\x` | 反斜杠原样保留 |

要输出“字面量花括号 + 真占位符”：`\\{{x}}` → `\` + x 的值。
例：`\{{not_var}} vs {{real}}`（real=R）→ `{{not_var}} vs R`。

## 3. 嵌套替换与循环识别

- 变量值内再次出现 `{{ other }}` 时，按同一份变量表继续展开，层数不限：
  `a="1{{b}}2"`, `b="3{{c}}4"`, `c="!"`，`{{a}}` → `13!42`。
- 沿解析栈做环检测：引用链中出现重复变量名即抛 `CycleError`，
  异常消息给出完整链路，例如 `a -> b -> c -> a`。
- 用户内容（变量值）中的 `{`、`}`、`}}` 一律按字面量处理；
  变量值里未闭合的 `{{` 退化为字面量而不是报错——用户花括号永远撑不坏模板结构。
  变量值里合法的 `{{name}}` 按嵌套引用处理，若 name 缺失同样报缺失错误。

## 4. 变量缺失策略

- 缺失即抛 `MissingVariableError`，**不留空、不删除整段、不静默继续**。
- 异常消息包含缺失名和全部可用变量名，例如：
  `缺失变量 'ghost'；当前可用变量: age, name, other`。
- 非字符串变量用 `str()` 转换后参与替换。

## 5. 结构对拍

`structural_diff(template, rendered, variables)` 把模板重新切成
“字面量片段 / 占位符片段”，逐片段与渲染结果对齐比对：

- 字面量片段（转义按还原后内容）必须逐字符不变；
- 占位符片段必须等于该变量含嵌套展开后的值；
- 渲染结果多出的尾部记为 `trailing` 片段并标记 DIFF。

实测对拍数据见 `diff_report.txt`（含正常用例全部 OK，以及一个尾部注入被
判为 DIFF 的防篡改用例），复现：`python3 diff_demo.py`。

## 6. 耗时与内存（10 万次）

模板长度 93 字符、5 个顶层占位符 + 1 层嵌套，输出 127 字符；
环境 Python 3.12.3 / linux（数据见 `bench_report.txt`）：

| 指标 | 数值 |
|------|------|
| 总耗时 | 约 2.0 s（100,000 次） |
| 单次耗时 | 约 20 µs |
| 吞吐 | 约 4.9 万次/秒 |
| Python 堆工作集峰值 | 4.4 KiB（tracemalloc） |
| 进程 RSS 增量 | 0 MiB（ru_maxrss，基准前后无增长） |

说明：耗时轮不挂 tracemalloc（跟踪会拖慢分配约 5 倍）；内存轮单独采样。

## 7. 边界用例（test_template_engine.py，30 项）

- 无占位符：纯文本（含单花括号）、空模板，输出与输入逐字符一致。
- 多层嵌套：一层/三层嵌套、模板与变量值同时引用同一变量。
- 循环展开：二元环、自引用、三元环并校验报告链路。
- 转义：`\{{`、`\}}`、`\\`、孤立反斜杠，输出还原为字面量。
- 变量缺失：顶层缺失、嵌套值中缺失、空变量表，均列出可用变量名。
- 用户花括号：值中含 JSON 式 `{...}` 不破坏结构；值中未闭合 `{{` 按字面量。
- 结构对拍：正常全 OK；篡改尾部、改写字面量均能检出 DIFF。
- 语法错误：未闭合占位符、非法变量名。

## 8. 文件与运行命令

```
template_lib/
├── template_engine.py     # 库: render / tokenize / structural_diff
├── test_template_engine.py# 30 项自测
├── bench.py               # 10 万次耗时/内存基准
├── diff_demo.py           # 结构对拍数据演示
├── diff_report.txt        # 固化的对拍数据
├── bench_report.txt       # 固化的基准数据
└── TEMPLATE.md            # 本文档
```

```bash
cd template_lib
python3 -m unittest -v        # 自测
python3 diff_demo.py          # 查看结构对拍数据
python3 bench.py              # 10 万次基准（可传参数: python3 bench.py 50000）
```

库使用示例：

```python
from template_engine import render, MissingVariableError, CycleError

render("你好, {{name}}", {"name": "世界"})          # '你好, 世界'
render(r"\{{x}}={{x}}", {"x": 1})                    # '{{x}}=1'
```
