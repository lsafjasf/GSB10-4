# 调色板索引 <-> 真彩互转（Python 3，仅标准库）

## 文件
- `palette_lib.py` — 库：双向转换、最近色、量化、校验、误差统计
- `test_palette.py` — 自测（20 个用例）：`python3 test_palette.py`
- `bench.py` — 4096×4096 基准与误差统计：`python3 bench.py`

## 选色依据与距离度量
- 选色规则：对调色板全部条目取距离最小者（argmin），等距时取索引最小者，结果确定。
- 距离度量 `redmean`（默认）：低成本感知加权欧氏距离
  `d² = (2 + r̄/256)·Δr² + 4·Δg² + (2 + (255−r̄)/256)·Δb²`，绿色通道权重最大，符合人眼敏感度。
- 可选 `euclidean`：普通 RGB 欧氏距离平方。

## 超容量策略（不取模、不产生色带跳变）
`build_palette(rgb, capacity, strategy=...)`：
- 唯一色数 ≤ 容量：直接取全部唯一色，无损。
- `median-cut`（默认）：中位切分自适应量化，循环拆分像素数最多的色盒，
  沿最长通道按加权中位数切开，调色板条目为盒内加权平均色。
- `reject`：直接抛 `PaletteError`，拒绝降级。

## 校验与报错位置
- 调色板为空 / None / 超 256 条 → `PaletteError`
- 条目缺失（None）、长度 ≠ 3、通道非 int 或越界 → 报 `palette entry i`
- 真彩数据长度非 3 的倍数 → 报起始字节位置
- 索引越界 → 报 `pixel i`（第一个越界像素）
- 所有异常带 `.position` 属性。

## 性能（4096×4096，65536 唯一色，256 色调色板，实测）
| 阶段 | 耗时 |
|---|---|
| 真彩→索引（颜色缓存 + KD 树） | ~3.0 s |
| 真彩→索引（朴素逐像素线性扫描，256² 外推 ×256） | ~708 s |
| 加速比 | ~233× |
| 索引→真彩（查表 join） | ~1.7 s |
| 直方图 / median-cut / 误差统计 | 2.2 / 2.6 / 1.0 s |

优化原理：每个不同颜色只查一次（dict 缓存），单次查询用 KD 树 O(log k)；
朴素法每像素扫全部 256 条目。误差统计按唯一色加权计算，与逐像素等价但快得多。

## 往返误差（真彩→索引→真彩，median-cut 256 色）
- 最大单通道误差：39/255
- 平均单通道误差：10.41/255

## 边界用例（test_palette.py 覆盖）
单色图精确往返、256 满色板恒等映射、1000 色超容量量化/拒绝、空调色板、
条目缺失/长度不符、索引越界、未知度量/策略/非法容量、空索引图、等距决胜。
