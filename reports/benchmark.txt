== 性能数据：10 万会话 / 100 万次选择 ==
环境：Python 3.12.3，10 后端，capacity=15000，160 虚节点/后端

耗时
  A 冷绑定 100,000 会话（含 1 次状态写） : 1.076 s  (92,919 次/秒)
  B 1,000,000 次选择                    : 5.418 s  (184,580 次/秒)  outcomes={'ok_pinned': 900000, 'ok_new': 100000, 'other': 0}
    单次选择耗时上界                      : 5.42 us
  C 漂移：摘除 b03，迁移 19,625 会话 : 1.613 s  (12,167 迁移/秒)
  D 漂移后 100,000 次选择               : 0.087 s  (1,155,937 次/秒)  确定=True

内存
  tracemalloc Python 峰值（A+B+C 后）   : 190.3 MB
  折合每会话                            : 1.90 KB
  进程 RSS 峰值（ru_maxrss）            : 209 MB

正确性
  漂移迁移统计                          : {'migrated': 19625, 'rejected': 0, 'failed': 0, 'lost': 0}
  全量对拍不一致数（期望 0）            : 0
  漂移后选择确定性                      : True
  漂移后各后端负载                      : {'b00': 22607, 'b01': 21438, 'b02': 21056, 'b03': 0, 'b04': 23342, 'b05': 22825, 'b06': 20681, 'b07': 23208, 'b08': 21795, 'b09': 23048}

理论上界（n=会话数, m=后端数, v=每后端虚节点=160）
  pin 表内存   : O(n)，条目为小 dataclass（约 ~150 B/会话）
  哈希环内存   : O(m*v)，10 后端约 1,600 个点，可忽略
  选择耗时     : O(log(m*v)) ~ O(1)（bisect + 至多 m 次顺时针探测）
  摘除迁移耗时 : O(k * log(m*v))，k=该后端上会话数
