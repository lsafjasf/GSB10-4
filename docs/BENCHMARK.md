# 基准：100 万次键构造

环境：Python 3.12.3（CPython，单进程），仅标准库。
命令：`python3 bench/bench_keys.py`（可用 `--n` 调整次数）。

语料：10,000 个预生成的真实风格请求（单值 Content-Type、多值 Accept /
Accept-Language、大小写混用的 Accept-Encoding、raw Cookie，其中 5% 携带
500–4500 字节的超长 analytics cookie），循环构造 1,000,000 次。

## 结果

| 指标 | 数值 |
|---|---|
| 构造次数 | 1,000,000 |
| 总耗时 | 17.324 s |
| 吞吐 | 57,722 keys/s |
| 平均单次 | 17.32 µs |
| 超长走哈希路径 | 4,000（0.40%） |
| 不同键数量 | 9,927（归一化合并了语料中的等价变体，符合预期） |

## 键长分布（字符数）

| 分位 | 长度 |
|---|---|
| min / mean / max | 48 / 453.6 / 5459 |
| p50 / p90 / p99 / p99.9 | 395 / 462 / 3363 / 5183 |

| 区间 | 数量 | 占比 |
|---|---|---|
| [0,128) | 4,000 | 0.40%（全部为 `HK1H$` 哈希键，固定 48 字符） |
| [256,512) | 968,500 | 96.85% |
| [512,1024) | 6,000 | 0.60% |
| [1024,2048) | 5,000 | 0.50% |
| [2048,4096) | 10,300 | 1.03% |
| [4096,8192) | 6,200 | 0.62% |

上界验证：直接键最大 5459 < 5466（`4 + ceil(4096*4/3)`），与规则一致；
所有超界键均为固定 48 字符的哈希键，无截断。
